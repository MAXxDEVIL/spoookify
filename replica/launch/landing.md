# Spoookify - Landing Page

## Hero
**Spoookify**  
*Your spooky soundscape*

A clean music streaming experience for your playlists and library. 
Built for web, mobile, and terminal.

## Features
- Stream with your own library
- Create and manage playlists
- Search tracks, artists, albums
- Listen on mobile or CLI
- Dark theme, fast and minimal

## Tech
- Next.js API
- React Native (Expo) Mobile
- Go + Bubbletea CLI
- PostgreSQL + Drizzle

## Get Started
```bash
# Start API
cd apps/api && pnpm dev

# Start CLI
cd apps/cli && go run ./cmd/spoookify
```
